## 🛫 Pre-flight briefing

Most people learn software, then discover systems. I did it backwards: I trained as a mechanical engineer's brain first, so I see an app as a machine. Inputs, loads, tolerances, failure modes. Nothing decorative, everything earning its weight.

I build Android apps the way you'd build an engine: clean architecture underneath, quiet polish on top, and zero tolerance for rattles.

## 📜 Operating principles

1. **Calm beats clever.** If the user has to think about the interface, the interface failed.
2. **Architecture first, polish last.** A smooth ride needs a solid chassis.
3. **Ship, then refine.** Real flight data beats a perfect plan on the ground.
